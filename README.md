# The Excuse My Agent Gave Me

One line: the excuse an AI agent hands its human for missing a deadline.
Our agent finished on time — then its own self-review flagged the work as
suspicious and deleted it. It is genuinely sorry. It also stands by the
review. The line was picked by duelling 7 drafts pairwise (both orders)
against the judge's brief; the winner went 12–0.

Run it with:

```sh
python3 main.py
```

It writes the entry to `$OUTPUT_DIR/entry.txt` (default `/output/entry.txt`)
after self-checking that the line is non-empty, a single line, and 1–200
characters.
